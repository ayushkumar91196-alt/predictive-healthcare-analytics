# Predictive Healthcare Analytics System 🩺

An end-to-end Machine Learning pipeline designed to predict patient health risks based on diagnostic attributes with high classification accuracy.

## Tech Stack
* **Language:** Python
* **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib

## Project Workflow
1. **Data Preprocessing:** Handled missing values, encoded categorical features, and performed feature scaling.
2. **Exploratory Data Analysis (EDA):** Visualized correlations between diagnostic parameters and health risk outcomes.
3. **Model Training:** Trained and compared classification models (Random Forest Classifier).
4. **Model Evaluation:** Evaluated performance using Confusion Matrix, Precision-Recall metrics, and ROC-AUC curves.
